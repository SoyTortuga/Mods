COLLECTION NAME
Moon Sweepers Twitch Sabotage


SUMMARY (the short line under the name)
Everything you need for Twitch chat to sabotage your Moon Sweepers crew: BepInEx, the patcher and the Twitch Integration mod, set up in one click.


DESCRIPTION
Install this collection and Vortex sets up BepInEx 6 (IL2CPP), the MoonSweepers BepInEx Patcher and Moon Sweepers Twitch Integration together.

Who needs it:
- The streamer: connects the mod to Twitch and sets which Power-ups trigger which effects.
- Everyone else in the crew: install the collection and join the streamer's lobby. No Twitch account needed.

After installing, start the game once. The first start takes about 15 seconds longer while BepInEx sets itself up.

Streamers: follow "Streamer setup" on the Moon Sweepers Twitch Integration page to sign in to Twitch and map your Power-ups.

Crew: you're done. If you'd rather not see the Twitch sign-in prompt, open BepInEx\config\com.soytortuga.moonsweepers.twitch.cfg after the first start and set Enabled = false under [Twitch].

Note: Twitch Bits and Power-ups need the streamer to be a Twitch Affiliate or Partner.


PER-MOD INSTRUCTIONS (the text Vortex shows for each mod; optional)

BepInEx 6.0.0-be.791 (IL2CPP win-x64)
Must be this exact build (b782da4). Other BepInEx builds don't work with the patcher.

MoonSweepers BepInEx Patcher
Makes BepInEx work on this game's version of Unity. The first game start after installing takes about 15 seconds longer.

Moon Sweepers Twitch Integration
Streamers: see Streamer setup on the mod page. Crew: nothing to do.
